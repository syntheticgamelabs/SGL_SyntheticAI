# SGL SyntheticAI - Windows Client v1.1.39

AI-powered cybersecurity desktop client by Synthetic Game Labs.

## Quick Start (Pre-built)
Run `build/SGL.JudgeDredd.App.exe` to launch the client.

## Build from Source
**Requirements:** .NET 8.0 SDK, Windows 10+

```bash
dotnet build SGL-AI-Client.slnx -c Release
dotnet publish src/SGL.JudgeDredd.App -c Release -r win-x64 --self-contained
```

Or run `build.bat` for a one-click build.
