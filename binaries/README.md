## Windows Server Download

The Windows Server installer (~54 GB) includes bundled LLM models, Stable Diffusion WebUI, and Python runtime. Due to size constraints, it is not distributed via Git.

**To obtain the server installer:**
- Contact: security@syntheticgamelabs.com
- Download from: [syntheticgamelabs.com/download](https://syntheticgamelabs.com/download)

The Linux publish directories contain the full .NET self-contained application. The `install.sh` scripts are included here; full packages are available via download.
