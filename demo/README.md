- Drop EICAR test file into monitored directory
- Show real-time detection alert
- View SecurityBrain threat assessment breakdown
- Show quarantine vault with isolated file

- Chat: "What is the current threat landscape?"

- Show server metrics (CPU, RAM, disk, connections)
