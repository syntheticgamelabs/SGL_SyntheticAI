# Contributing to SyntheticAI

Thank you for your interest in SyntheticAI.

## Repository Scope

This public repository contains documentation, architecture descriptions, research concepts, and safe demonstration modules. The production platform is maintained in private repositories.

## How to Contribute

### Documentation Improvements
- Fix typos, clarify explanations, improve diagrams
- Submit a pull request with a clear description

### Demo Module Enhancements
- Improve the demonstration code in `/demo/` and `/examples/`
- Ensure changes don't introduce security vulnerabilities
- Keep demo code simple and educational

### Research Discussion
- Open an issue to discuss security research concepts
- Propose new detection approaches or architectures
- Share relevant academic references

### Bug Reports
- Report issues with demo code or documentation
- Include steps to reproduce any problems

## What NOT to Contribute

- **Do not** submit production-grade detection algorithms (we maintain these privately)
- **Do not** include real malware samples or exploit code
- **Do not** submit code that requires proprietary dependencies

## Code Style

For C# demo code:
- Follow standard .NET naming conventions
- Include XML documentation comments
- Add copyright header to all files
- Keep dependencies minimal
